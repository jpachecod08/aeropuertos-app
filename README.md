# Aeropuertos del Mundo

Aplicación web construida con Next.js para explorar aeropuertos alrededor del mundo.

## Características

- Listado paginado de aeropuertos
- Búsqueda por nombre o código
- Detalles completos de cada aeropuerto
- Mapa interactivo con la ubicación
- Modo oscuro/claro
- Historial de búsquedas
- Diseño responsive

## Tecnologías

- Next.js 14
- TypeScript
- Zustand (gestión de estado)
- Tailwind CSS
- Leaflet (mapas)
- Jest + Testing Library

## Configuración

1. Clona el repositorio
2. Instala dependencias: `npm install`
3. Crea un archivo `.env.local` con tu API key de Aviationstack:
4. Corre en local con `npm run dev`
